# Meratune Revenue Dashboard

This dashboard is built from `Meratune Customer data.xlsx`.

## Files
- `index.html` — dashboard page
- `style.css` — dashboard design
- `app.js` — filtering, KPIs and charts
- `data.csv` — source data

## IMPORTANT — privacy
The CSV contains customer mobile numbers. Keep the GitHub repository **PRIVATE**.
Do NOT enable ordinary public GitHub Pages for this repository unless you have a GitHub Enterprise Cloud setup that provides private Pages access.

## GitHub setup
1. Create a new **Private** repository.
2. Upload all four files.
3. Keep the repository private.
4. For an authenticated management-facing URL, use an authenticated hosting/deployment option rather than standard public GitHub Pages.

## Updating data
Replace `data.csv` with the latest CSV exported from Excel, keeping these column names:
Mobile Number, Invoice Amount, Date, Amount
